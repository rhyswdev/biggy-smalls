# F-01 · prompt · efficiency · seen in every run reviewed

**What happened.** Every board update was sent in a turn of its own, with no reads beside it. The reads that the update called for went out in the next turn. In each run, about a third of the model turns held nothing but a board update. Every turn sends the whole conversation again, so these turns add wall time and input cost and buy nothing: the status line at the end of a round already reflects a board update made in that round.

**What the method says.** In one turn, make every independent read the round needs, together with the board update for the last results.

**Fixed when.** In most rounds after the first, the board update and the next reads go out in the same turn, and a run needs clearly fewer model turns for about the same number of reads.

**Keep.** The rest works, and runs reach sound conclusions. Keep the order of the investigation (hypotheses written early, discriminating checks, the owner lookup), the citation rules, the confidence rubric and the stopping rule.
